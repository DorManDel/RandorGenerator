CONTRACT

Keep the responsibilities separate

UI ShellNavigation, view mode, responsive camera preview
Capture AdapterBrowser camera → grayscale / frame differences
Measurement LayerSource health, time series, reproducible reports
Secure Random LanePlatform CSPRNG / approved algorithms
Private API & CollectorFuture authenticated remote cameras

Reading the dashboard

Camera: the source image. Grayscale: its 160×120 brightness approximation. Frame Difference: pixels changed from the previous sampled frame.

Source FPS: frames supplied or drawn by the browser. Sent FPS: rate of analyzed frames (no remote sending in this prototype).

Signal health: a motion/contrast heuristic, not an entropy estimate or cryptographic security score.

Capture, Test and Keys: these are separate workflows. The crypto tools rely on the browser CSPRNG.
